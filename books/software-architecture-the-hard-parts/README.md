## 共享术语与写作边界

| 英文 | 统一译法／含义 |
| --- | --- |
| trade-off analysis | 权衡分析；解释具体约束下的收益与代价 |
| architecture characteristic | 架构特性（与质量属性相关，不等同于业务功能） |
| architecture quantum / quanta | 架构量子；结合部署、功能内聚、静态依赖及运行时同步耦合分析，不按进程或服务框机械计数 |
| coupling / cohesion | 耦合／内聚 |
| static / dynamic coupling | 静态耦合／动态耦合；运行所需的接线依赖／运行时协作依赖 |
| architectural decision record / ADR | 架构决策记录 |
| architecture fitness function | 架构适应度函数；客观检验架构特性的机制，不能保证全部业务正确 |
| component / service | 组件／服务；代码组织单元／作为独立可执行体部署的内聚功能集合 |
| bounded context | 限界上下文；与架构量子有关但不等同 |
| orchestration / choreography | 编排／协同 |
| operational / analytical data | 运营数据／分析数据；运营数据不是机器运维指标 |
| scalability / elasticity | 可扩展性／弹性；承载持续增长／应对突发负载的能力 |
| extensibility | 功能可扩展性；扩展业务能力，与 scalability 的负载承载能力区分 |
| service-based architecture | 基于服务的架构；本书特指粗粒度领域服务与共享数据库的架构风格 |
| component-based decomposition / tactical forking | 基于组件的分解／战术分叉 |
| afferent / efferent coupling | 传入耦合 Ca／传出耦合 Ce |
| abstractness / instability / distance | 抽象度 A／不稳定性 I／主序列距离 D；区分归一化距离和几何距离 |
| architecture story | 架构故事；为架构特性或业务目标记录结构性重构工作，区别于决策记录 ADR |
| component domain / domain service | 组件领域／领域服务；逻辑分组／提取后的粗粒度可部署服务 |
| data domain / schema | 数据域／数据库模式（schema）；架构归属与数据库对象容器，不能由分 schema 推导已完成故障隔离 |
| disintegrator / integrator | 拆分驱动力／聚合驱动力；数据与服务粒度各有对应维度 |
| shared library / shared service | 共享库／共享服务；使用方纳入自身部署的制品／运行时调用的独立服务 |
| Sidecar / service mesh | Sidecar（边车）／服务网格；基础设施复用不自动解决领域工作流、幂等或事务 |
| single / common / joint ownership | 单一／共同／联合所有权；分别为单个服务、广泛服务、少数同域服务写入；读得多不自动获得写所有权 |
| delegate technique | 委托技术；由唯一所有者执行其他服务请求的写入，不将副本读取权扩写为权威写入权 |
| column schema replication | 列模式复制；在消费方数据模型保存所需字段副本，需管理更新和权威来源 |
| replicated cache / distributed cache | 复制缓存／分布式缓存；本章分别指各服务内的完整副本与外部缓存服务，不能只按产品名判断拓扑 |
| semantic / implementation coupling | 语义耦合／实现耦合；给定业务要求下必须共同完成的工作／为兑现它而引入的技术联系 |
| front controller / stamp coupling | 前置控制器／印记耦合；入口领域服务兼管状态／在传递的数据结构中携带超出单个参与者所需的信息，含工作流状态的用途 |
| compensating transaction / update | 补偿事务／补偿更新；新的业务操作纠正已提交效果，不是撤回历史可见性的数据库回滚 |
| transactional saga | 事务Saga；本书八组合按通信s/a、一致性a/e、协调o/c命名；atomic端是整体结果目标，不自动具有ACID隔离保证 |
| strict / loose contract | 严格／宽松契约；实际约束程度的连续谱，不由序列化格式或通信框架名称直接决定 |
| consumer-driven contract | 消费者驱动契约；消费方声明实际交互依赖，提供方持续验证，不等于完整业务与投递验证 |
| data mesh | 数据网格；领域数据所有权、数据即产品、自助式数据平台、联邦计算治理共同支持的社会技术方法 |
| data product quantum / DPQ | 数据产品量子；分析数据、代码、元数据和必要基础设施形成的内聚交付单位 |
| cooperative quantum | 协作量子；运营与分析运行分离但领域语义紧密相关，不能与 choreography（协同）混同 |
| federated computational governance | 联邦计算治理；共同制定跨域规则并将可执行部分落实到平台和产品 |
| MECE | 相互排斥、整体穷尽；分类无重叠且覆盖明确范围，不指统计独立或穷举全部产品 |
| atomicity / isolation / business consistency | 原子性／隔离性／业务一致性；整体提交效果、并发可见性和业务不变量分别论证 |
| orthogonal coupling | 正交耦合；基础设施或分析供给等责任沿另一条轴组织，仍保留领域语义与运行依赖 |
